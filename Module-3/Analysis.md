# Module 3 or Unit 3: Display Lists and Use Material Design

## Overview

Unit 3 focused on displaying collections of data and improving Android app interfaces using Jetpack Compose and Material Design. The unit covered additional Kotlin fundamentals, scrollable lists, grids, Material Design components, animations, and accessibility.

## What I Learned

### Pathway 1: More Kotlin Fundamentals

* Learned additional Kotlin programming concepts.
* Improved my understanding of functions, collections, and other Kotlin features used in Android development.

### Pathway 2: Build a Scrollable List

* Learned how to display lists of text, images, and other content.
* Used Compose components to create scrollable layouts.
* Learned how to organize repeated data using reusable UI components.

### Pathway 3: Build Beautiful Apps

* Learned how to use Material Design components.
* Learned how to improve the visual appearance and usability of an application.
* Practiced using grids, animations, and accessibility concepts.

## Analysis

Unit 3 helped me understand how to display larger amounts of information in an organized and user-friendly way. I learned how lists and grids can be used to present repeated data efficiently instead of creating each UI element separately. I also improved my understanding of reusable Compose components, which makes the code easier to organize and maintain.

I applied these concepts by building several applications, including the **Affirmation App, Grid Courses, Superheroes App, and Woof App**. These projects gave me practical experience displaying lists, images, and course or item information. The Grid Courses project helped me understand how data can be presented in a grid layout, while the Superheroes and Woof apps helped me practice creating structured list-based interfaces.

The unit also introduced Material Design and accessibility principles. This helped me understand that an Android application should not only function correctly but should also have a clear, consistent, and easy-to-use interface.

## Outcome

After completing Unit 3, I can create Android applications that display data using scrollable lists and grid layouts. I can create reusable Compose components to reduce repeated code and organize application interfaces more effectively.

Through the practical projects, I gained experience working with images, lists, grids, Material Design components, and structured UI layouts. I also developed a better understanding of how good UI design, accessibility, and organization can improve the overall user experience of an Android application.
