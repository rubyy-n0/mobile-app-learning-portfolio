# Module 1 or Unit 1: Your First Android App

## Overview

Unit 1 introduced the basic concepts needed to start Android development using Kotlin, Android Studio, and Jetpack Compose. The unit was divided into three pathways: Kotlin programming, Android Studio setup, and building a basic Android layout.

## What I Learned

### Pathway 1: Introduction to Kotlin

* Learned basic Kotlin syntax and program structure.
* Learned how to create variables and use functions.
* Practiced basic Kotlin programming concepts.

### Pathway 2: Setup Android Studio

* Installed and configured Android Studio.
* Created my first Android project.
* Learned how to run an Android application using an emulator or physical device.

### Pathway 3: Build a Basic Layout

* Learned the basic concept of Jetpack Compose.
* Used text and image composables to create a simple user interface.
* Created a basic Android application layout.

## Analysis

Unit 1 provided the foundation for Android development. I learned how Kotlin code connects with Android Studio and how Jetpack Compose can be used to create user interfaces. The practical exercises also helped me understand the basic process of creating, running, and testing an Android application.

## Outcome

After completing Unit 1, I can create a basic Android project, write simple Kotlin code, design a simple Compose interface, and run the application on an emulator or Android device.
