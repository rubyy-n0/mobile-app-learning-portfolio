# Module 2 or Unit 2: Building App UI

## Overview

Unit 2 continued the fundamentals of Kotlin and introduced interactive Android app development using Jetpack Compose. The unit covered Kotlin fundamentals, button interactions, UI state, user input, and basic testing.

## What I Learned

### Pathway 1: Kotlin Fundamentals

* Learned how to use conditionals and nullability in Kotlin.
* Learned about classes, objects, function types, and lambda expressions.
* Practiced basic object-oriented programming concepts.

### Pathway 2: Add a Button to an App

* Learned how to add buttons to a Compose UI.
* Learned how to respond to user button clicks.
* Used the Android Studio debugger to identify and fix problems.

### Pathway 3: Interacting with UI and State

* Learned how state works in Jetpack Compose.
* Learned how user input can update the UI automatically.
* Created a tip calculator using user-entered data.
* Learned how to write basic automated tests.

## Analysis

Unit 2 helped me move from basic Android UI development to creating more interactive applications. Through the Kotlin exercises, I practiced conditionals, classes, objects, nullability, and lambda expressions. These concepts helped me understand how application logic is written and organized.

I also developed several small applications, including a **Dice Roller**, **Lemonade App**, **Tip Time Calculator**, and **MyArtSpace**. These projects gave me practical experience with buttons, user interactions, state, user input, and displaying different content on the screen. The Tip Time Calculator helped me understand how user-entered values can be processed and displayed as updated results, while MyArtSpace helped me practice creating a structured Compose UI for displaying artwork.

Overall, Unit 2 improved my understanding of how Jetpack Compose manages UI changes through state and recomposition. I also gained experience using the Android Studio debugger and writing basic automated tests, which helped me understand how to identify problems and check application functionality.

## Outcome

After completing Unit 2, I can create more interactive Android applications using Kotlin and Jetpack Compose. I can add buttons, handle user actions, receive user input, manage application state, and update the UI when data changes.

By completing the Dice Roller, Lemonade, Tip Time Calculator, and MyArtSpace projects, I gained practical experience in building different types of Compose applications. I also learned how to debug application issues and perform basic testing. These skills give me a stronger foundation for developing more complete Android applications in the next units.
