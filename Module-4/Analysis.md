
# Module 4 or Unit 4: Navigation and App Architecture

## Overview

Unit 4 focused on building more structured and scalable Android applications. The unit introduced Android app architecture, ViewModels, UI state, StateFlow, navigation between screens, and adaptive layouts. It also introduced techniques for creating applications that provide a better user experience across different screen sizes.

## What I Learned

### Pathway 1: Architecture Components

* Learned about the Activity lifecycle and its different stages.
* Learned the principles of modern Android architecture.
* Learned how to use ViewModel to manage UI-related data and state.
* Learned how StateFlow and UDF can be used to manage state and events.
* Practiced writing unit tests for ViewModels.

### Pathway 2: Navigation in Jetpack Compose

* Learned how to navigate between different screens using Jetpack Compose.
* Learned how to use the Navigation component.
* Learned how to pass data between different screens.
* Practiced navigation and testing through the Cupcake App.

### Pathway 3: Adapt for Different Screen Sizes

* Learned the principles of responsive and adaptive UI design.
* Learned how window size classes support different screen sizes.
* Learned how to create dynamic navigation for different form factors.
* Practiced building adaptive layouts through the Reply, Sports, and My City applications.

## Analysis

Unit 4 helped me understand how Android applications can be organized into a structured architecture as they become larger and more complex. I learned how ViewModel can separate UI-related state and logic from composable functions, making the application easier to maintain and manage.

I also learned how **StateFlow and the Unidirectional Data Flow (UDF) pattern** can be used to manage state and events. Compared with the simpler state management introduced in earlier units, these approaches provide a more organized way to handle data in applications with more complex functionality.

I applied these concepts by building several applications, including the **Dessert Clicker, Unscramble, Cupcake, Reply, and Sports apps**. The Dessert Clicker and Unscramble apps helped me practice managing application state and separating logic from the UI. The Cupcake App provided practical experience with multi-screen navigation and passing information between screens.

The Reply and Sports apps helped me understand how an application can adapt its interface to different screen sizes. These activities showed me that responsive design is important when developing applications for different devices and form factors rather than designing only for a single screen size.

Overall, the practical projects helped me connect the architecture, state management, navigation, and adaptive UI concepts introduced throughout Unit 4.

## Outcome

After completing Unit 4, I can apply modern Android architecture concepts when developing applications. I can use ViewModel to manage UI-related state and understand how StateFlow and UDF can organize state and events.

I can also create multi-screen applications using Jetpack Compose Navigation and understand how navigation routes and data passing work. In addition, I can apply adaptive UI concepts to create layouts that respond to different screen sizes and device types.

Through the five applications I developed, I gained practical experience with **state management, ViewModel, navigation, multi-screen applications, adaptive layouts, and testing**. These skills improved my ability to structure Android applications beyond basic UI development.
